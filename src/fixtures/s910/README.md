# S-910 runtime WebVTT fixture

`assets/caption-stage.webm` is a dedicated, Git-managed 640×360, 15fps VP8 reel generated by FFmpeg. The red circle, blue triangle, and yellow square are pixels encoded into the video at the cue intervals defined by the generator and runtime cue code; CSS does not supply the symbols. The player still creates the captions with runtime `VTTCue` objects, so no prerecorded caption file participates in the puzzle.

Regenerate the fixed asset only with:

```powershell
$env:BUSYCUBE_FFMPEG_PATH = "<trusted-ffmpeg-path>"
$env:BUSYCUBE_FFPROBE_PATH = "<trusted-ffprobe-path>"
node scripts/generate-busycube-s900-s910-fixtures.mjs
```

The generator verifies FFmpeg probe metadata immediately after encoding. Runtime cue selection remains covered as application logic; normal CI does not revalidate the committed WebM bytes.

As with S-900, the generator normalizes FFmpeg's randomized WebM `TrackUID` after encoding so identical inputs are byte-for-byte reproducible. No separate checksum registry is maintained.
