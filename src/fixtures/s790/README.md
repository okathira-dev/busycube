# S-790 Busycube Key Two font

`assets/busycube-key.ttf` is a deterministic, project-original TrueType-flavoured OpenType fixture generated by `scripts/generate-busycube-s790-font.mjs`. Four block letter glyphs at U+E001–U+E004 spell CUBE. No third-party font outlines are used.

The stage downloads the file for OS installation. It queries only `BusycubeKeyTwo-Regular`, verifies the SHA-256 contract, and constructs a FontFace solely from the returned FontData.blob(). The distributed file is never loaded directly to display the puzzle. Reading the font does not open the box; the passphrase must be entered afterward.

The new family/PostScript name avoids confusing the old one-glyph PoC installation with this phrase font. Page cleanup releases its loaded face; the verified bytes go directly into FontFace and no Blob URL is created; OS removal is a separate device setting. Old B01 progress is retained as history and is not transferred to B02.

Regenerate with the repository's pinned Node runtime:

```powershell
node scripts/generate-busycube-s790-font.mjs
```
