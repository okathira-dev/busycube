# 全ステージ・人手確認台帳

現行の89ステージ・204箱について、画面レビュー、ブラウザ権限、実機センサー、PWA、OAuth、外部機器、環境差の確認結果を一件ずつ記録する作業台帳の入口。
解法仕様の正本は各 `src/stages/S-xxx/stage.tsx` の日本語JSDocであり、以下の文書は確認項目、実施環境、結果、証跡を管理する。
全必須項目の証跡が揃い、未検証範囲が利用者向け画面へ反映された後は、この一時台帳一式を削除する。

## 台帳

- [実環境・公開判定](./stage-review-environments.md): ブラウザ、OS、端末、PWA、権限、外部機器の確認ケースと公開可否
- [ステージレビュー共通手順](./stage-review-guide.md): チェックの意味と全ステージ共通の横断レビュー
- [Dステージ](./stage-review-d.md): 権限不要のBaselineステージ38件
- [Pステージ](./stage-review-p.md): 権限が必要なBaselineステージ26件
- [Lステージ](./stage-review-l.md): 対応環境が限定されるステージ25件

## 進め方

1. 共通手順と実環境・公開判定の条件を確認する。
2. D、P、Lの順に個別ステージをレビューする。
3. 実機や権限が必要な結果は、個別チェックだけで完了にせず実環境・公開判定台帳へ証跡を残す。
4. 用意できない環境は未検証のまま明示し、推測で合格にしない。
