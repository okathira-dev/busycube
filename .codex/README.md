# Codex setup

このディレクトリには Busycube 専用の共有 Codex 設定を置きます。

- `../AGENTS.md`: プロジェクトルールと FSL Skills の索引
- `config.toml`: Serena MCP のプロジェクトスコープ設定

## 初回利用

1. このリポジトリを Codex で trusted project として開きます。
2. `serena` コマンドを利用できる環境にします。
3. Codex を再起動し、Serena が接続済みであることを確認します。

共有設定には PAT、API キー、個人用 MCP 設定、ローカル PC 固有のパスを追加しないでください。
