# Busycube: Web API Explorer

日本語 · [English](./README.en.md)

> いつものブラウザが、パズルになる。

Busycube は、ブラウザそのものを手掛かりにするパズルゲームです。タブや URL、ファイル、端末の反応を観察して、箱を開けていきましょう。

[Busycubeを遊ぶ](https://busycube.okathira.com/) · [Play in English](https://busycube.okathira.com/?locale=en)

## 遊び方

ステージを選び、箱の近くにある手掛かりを観察します。画面の中だけでなく、ブラウザや端末のいつもの操作を試すことで、箱を開けられるかもしれません。

ステージは、遊ぶために必要な環境に応じて分かれています。

- **すぐプレイ**: ブラウザの権限を求めずに遊べるステージ。Windows の Chrome で動作を確認しています。
- **権限が必要**: カメラやマイクなどの許可を必要とするステージ。
- **対応環境限定**: 特定のブラウザや端末などで遊べるステージ。

「権限が必要」と「対応環境限定」のステージは暫定版です。内容や表示は今後変更する場合があります。

利用できるステージは、ブラウザや OS、端末、インストール状態、接続機器によって異なります。

## 権限と進捗

一部のステージでは、カメラ、マイク、位置情報、通知、外部機器などの権限を求めます。許可しない場合も、ほかのステージは遊べます。

進捗は通常、このブラウザに保存されます。希望する場合は、Google Drive のアプリ専用領域へバックアップできます。詳しくは[プライバシーポリシー](https://busycube.okathira.com/privacy/)と[利用規約](https://busycube.okathira.com/terms/)をご覧ください。
